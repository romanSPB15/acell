# Примеры

| Название                                                                             | Описание                                                                                  | Запуск                            |
|--------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|-----------------------------------|
| [`basic`](https://github.com/romanSPB15/acell/tree/main/examples/basic)              | Hello world на acell                                                                      | `go run ./examples/basic`         |
| [`demo`](https://github.com/romanSPB15/acell/tree/main/examples/demo)                | Анимированный Braille-логотип с TrueColor-градиентом на 30 FPS                            | `go run ./examples/demo`          |
| [`args`](https://github.com/romanSPB15/acell/tree/main/examples/args)                | События клавиатуры, мыши, колеса и фокуса; вывод terminfo и переменных окружения          | `go run ./examples/args`          |
| [`colorpicker`](https://github.com/romanSPB15/acell/tree/main/examples/colorpicker)  | Интерактивная 256-цветная палитра с RGB-миксером и копированием ANSI-констант по клику    | `go run ./examples/colorpicker`   |
| [`downsampling`](https://github.com/romanSPB15/acell/tree/main/examples/downsampling)| Downsampling цветов: TrueColor → 256 → 16 → 8                                             | `go run ./examples/downsampling`  |
| [`widerunes`](https://github.com/romanSPB15/acell/tree/main/examples/widerunes)      | Широкие руны (CJK) и анимированные градиенты                                              | `go run ./examples/widerunes`     |
