# Changelog

## [1.1.0] — 2026-09-24

### Added
- Пакет `terminfo` — детект возможностей терминала (`Info`, `ColorBits`).
- Downsampling цветов: TrueColor → 256 → 16 → 8 под доступную палитру.
- `Terminal.DrawString(x, y, style, str)` — рисует строку с поддержкой `\n` и `\r\n`.
- `Terminal.Info()` — возвращает `terminfo.Info` текущего терминала.
- Оптимизация перемещения курсора: `\033[H` для (0,0), `\033[nC` для близких сдвигов вправо.
- Поддержка `Dim`, `Strike`, `Hidden` в `Style`.

## [1.1.1] — 2026-09-24

### Fixed
- Конвертация RGB → 256 теперь использует стандартные 216 цветов палитры (индексы 16–231), а не базовые 16, зависящие от темы терминала.
- Проверка ошибок в `parseColorCode` — невалидные последовательности вида `38;5;` больше не парсятся как валидные.
- Тест `TestNearest256`.

## [v1.2.0] — 2026-09-30

### Removed
- Глобальные переменные в парсере ввода. Теперь несколько `RawTerminal` могут сосуществовать в одном процессе

### Changed
- Парсер ввода перенесён в `input` пакет

### Added
- Поддержка широких символов — `RuneWidth, Terminal.DrawRune`
- `Terminal.Invalidate` — полная перерисовка, ресайз без артефактов
- Константы цветов для 256-цветной и 16-цветной палитры
- `Terminal.SetTitle` — установка заголовка окна терминала (OSC 0)
- `Terminal.Write` — прямая запись в терминал в обход `Flush`
- `acell.TTY` — прямой доступ к терминалу, если stdout/stdin это pipe
- `WindowFocusEvent` — событие фокуса окна терминала
- `NewWithInfo` — конструктор с подменой `terminfo.Info`

### Internal
- Добавлены тесты для `terminfo`
- Общее покрытие: 61% -> 82%
